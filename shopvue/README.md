# ShopVue - Midterm Project (E-commerce Store)

Online store built with Vue 2, Vue Router, Vuex and axios.
Data comes from the mock service https://dummyjson.com

## Features
- Product catalog with categories, search and pagination
- Product page (dynamic route /product/:id)
- Shopping cart: add, change quantity, remove, total price
- Login (data saved in Vuex and localStorage), protected profile page
- Loading spinner and error messages

## Run
npm install
npm run serve

Open http://localhost:8080
